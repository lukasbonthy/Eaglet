# 🦅 Eaglet

### Eaglercraft 1.8 - but tiny.

**Eaglet** is a lightweight, optimized Eaglercraft 1.8 WASM-GC client focused on one thing:

> **How small and fast can Eaglercraft get while still feeling like Minecraft?**

The current Eaglet build is only around **2.65 MB** and runs from a **single HTML file**.
The current Eaglet build(with normal resources) is only around **3 MB** and runs from a **single HTML file**.
---

## ✨ Features

- 🦅 Around **2.65 MB**
- 📄 Entire client in **one HTML file**
- ⚡ WebAssembly GC runtime
- 🧱 Optimized **8× textures**
- 🔤 Original Minecraft-style font
- 📦 Highly compressed EPK/EPW assets
- 🌐 Runs directly in a supported web browser
- 💾 Works as a portable offline HTML
- 🎮 Singleplayer and multiplayer support
- 🚀 Focused on low-end devices and fast loading
